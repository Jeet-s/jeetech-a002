# Floria: Floria Mood Journal

Fast, private mood journal app free with emoji mood tracker and notes.

- Google Play: https://play.google.com/store/apps/details?id=com.jeetech.a002
- Privacy policy: https://jeet-s.github.io/jeetech-a002/privacy.html
- Current version: 1.0.0

`app/` is the Expo (React Native) source as shipped; `store/` holds the listing and graphics.
